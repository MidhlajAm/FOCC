# FOCC Member Handbook

## Joining
Anyone from any branch can join. Turn up at one session, make one contribution,
you are a member. There is no fee.

## Sessions
Weekly on Saturdays, 4 PM, CS Lab 2. Session recordings go on the club PeerTube.

## Contribution ladder
1. Attend a session
2. Open your first pull request on a club repo
3. Maintain a club repo
4. Mentor a first year

## Code of conduct
Be kind, assume good faith, credit other people's work. Harassment of any kind
means removal from the club.
